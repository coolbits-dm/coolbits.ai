# Milestone M4 — Knowledge Base Ingestion

## Objective
Use the hidden knowledge base files as the source of truth for Business, Agency, DevOps, About, and FAQ content, ensuring the assistant can cite real expertise without hallucinating.

## Deliverables
- `knowledge-base/*.md` rewritten with Bay-style copy about services, engagements, and FAQs.
- Mapping of knowledge entries to the chat bot’s guardrails (via `coolbits-*` prompts and `intent-router`).
- Documentation on how Andy should cite the knowledge base when answering operational questions.

## Outcome
The knowledge base now mirrors AWB documentation quality and feeds the portal when users ask for service details, enabling consistent, on-topic interactions.
