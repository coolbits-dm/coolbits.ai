# Milestone M2 — System Prompts & Intent Routing

## Objective
Define the nuclear system prompt, plus Business / Agency / DevOps guardrails, and build the intent router that classifies every incoming message into the correct vertical.

## Deliverables
- `coolbits-core`, `coolbits-business`, `coolbits-agency`, and `coolbits-devops` prompt files with tone, qualification, and redirect logic.
- `intent-router.js` with keyword heuristics, safety checks, and redirection messages.
- `suggestions.js` providing multilingual guidance for users unsure where to start.
- Clear mapping from the documents to Andy’s persona and the disclaimer logic.

## Observations
This milestone ensures the chat gateway understands the three pillars, deflects jailbreakers, and can escalate to the new knowledge base when needed. Camarad integration points are noted in the documentation as future work.
